```
## <exp> (branch: <exp>)
<2 sentences: question + hypothesis>
- YYYY-MM-DD HH:MM EST — <ablation>: <one-liner: what this ablation tests>
```

Failed experiments: add an entry here on main with branch, code changes, and why it failed.
